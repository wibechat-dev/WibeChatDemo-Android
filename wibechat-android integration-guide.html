Android integration guide

Add WibeChat calls to your Android app

Sign users in, ring someone, and join their call with a few lines of Kotlin. The calls kit talks to the WibeChat app server for you; the SDK carries the audio and video.

Step 1

Add the SDK

The SDK is on Maven Central. One of its dependencies is only served from JitPack, so add both repositories. The calls kit also uses OkHttp.

settings.gradle.kts
dependencyResolutionManagement {
    repositories {
        google()
        mavenCentral()
        maven("https://jitpack.io")
    }
}
dependencyResolutionManagement {
    repositories {
        google()
        mavenCentral()
        maven { url 'https://jitpack.io' }
    }
}
app/build.gradle.kts
dependencies {
    implementation("com.wibechat:wibechat-android:2.29.1")

Step 2

Add the calls kit

The calls kit is four Kotlin files that handle the whole call flow with the app server: sign-in, ringing, the call token, keeping call state in sync, and hanging up. Copy the calls folder from the wibechat-quickstart project into your app, or have an AI assistant write it with the prompt below.

wibechat-quickstart/app/src/main/java/com/wibechat/quickstart/calls/
WibeChatCalls.kt   the kit: signIn, startCall, join, hangUp, phase
AppServer.kt       the app-server API (/login, /ringCall, /callToken, ...)
SessionStore.kt    remembers the signed-in user and this install's ID
CallIds.kt         finds a call ID in pasted text, builds invite messages

Create one instance for the whole app, so a call keeps running while screens change.

MyApp.kt
class MyApp : Application() {
    val calls by lazy {
        WibeChatCalls(
            context = this,
            appServerUrl = "https://us-central1-wibechat-demo-2026.cloudfunctions.net",
        )
    }
}

// In AndroidManifest.xml: <application android:name=".MyApp" ...>
Step 3

Ask for permissions

The SDK already declares INTERNET, CAMERA and RECORD_AUDIO. Ask the user for the microphone (and the camera for video calls) before starting or joining.

CallActivity.kt
private var afterPermission: (() -> Unit)? = null

private val permissionLauncher =
    registerForActivityResult(ActivityResultContracts.RequestMultiplePermissions()) {
        if (hasPermission(Manifest.permission.RECORD_AUDIO)) afterPermission?.invoke()
        afterPermission = null
    }

fun withCallPermissions(video: Boolean, action: () -> Unit) {
    val missing = listOfNotNull(
        Manifest.permission.RECORD_AUDIO,
        Manifest.permission.CAMERA.takeIf { video },
    ).filterNot { hasPermission(it) }
    if (missing.isEmpty()) action() else {
        afterPermission = action
        permissionLauncher.launch(missing.toTypedArray())
    }
}
Step 4

Sign users in

Users sign in with their WibeChat email and password, or create an account. The kit remembers the session, so this happens once per install. Watch calls.session to switch between your sign-in and home screens.

SignInActivity.kt
lifecycleScope.launch {
    calls.signIn(email, password)                 // or calls.register(email, password, fullName)
        .onFailure { showError(it.message) }      // e.g. "Wrong email or password."
}

lifecycleScope.launch {
    calls.session.collect { session ->
        if (session == null) showSignIn() else showHome(session.fullName ?: session.email)
    }
}

calls.signOut()   // hangs up any call and forgets the session
Errors are ready to show.Every kit function returns a Result, never throws, and its failure message is written for users.

Show the call

        
Drive your screens from calls.phase. It moves through the phases below; the kit updates it when the other person joins, declines, cancels or hangs up. Pick a phase to see what to show.

    CallActivity.kt
    
          
    val room = calls.room
room.initVideoRenderer(binding.remoteVideo)   // once, in onCreate
room.initVideoRenderer(binding.localVideo)

// Your camera, once the phase is InCall
(room.localParticipant.getTrackPublication(Track.Source.CAMERA)?.track as? VideoTrack)
    ?.addRenderer(binding.localVideo)

// The other person's camera, when it arrives
lifecycleScope.launch {
    room.events.collect { event ->
        if (event is RoomEvent.TrackSubscribed) {
            (event.track as? VideoTrack)?.addRenderer(binding.remoteVideo)
        }
    }
}
    
        
    
      
    

      
    
        
    Step 7
    Mute and hang up
    
        
    Microphone and camera go through the room's local participant. hangUp() leaves the room and tells the server: it cancels the call if nobody answered yet, otherwise it marks the call ended, so the other phone closes too.
    
        
    
        
    
          
    CallActivity.kt
    
          
    fun toggleMute() = lifecycleScope.launch {
    val me = calls.room.localParticipant
    me.setMicrophoneEnabled(!me.isMicrophoneEnabled)
}

fun toggleCamera() = lifecycleScope.launch {
    val me = calls.room.localParticipant
    me.setCameraEnabled(!me.isCameraEnabled)
}

fun leave() = calls.hangUp()

    Behind the scenes
    
        
    What the kit does for each call. You only need this if you build without the kit or debug a problem.
    
        
    
        
      
        
      Secrets stay on the server.The app never sees the call license key or the server's API secret. Rooms and identities are chosen by the server from the signed-in user, so a call ID alone does not let anyone in.
      
      
      

      
      
        
      Next
      More features
      
        
      Building blocks beyond one-to-one calls. Each has a prompt that builds it on top of the calls kit.
      
        
      Ringing phones
      
        
      Today the person you call joins by pasting the shared invite. With push notifications their phone rings instead, and Accept joins the call. This needs Firebase Cloud Messaging and the app's google-services.json from the wibechat-demo-2026 Firebase project. The incoming push carries rk.type = "incoming", rk.callId, rk.callerName and rk.callType; Accept calls calls.join(callId).
      
        
      
        
      Group calls
      
        
      Ring everyone in a WibeChat group at once with /ringGroup; members join with the same calls.join(callId).
      
        
      
        
      A shared demo room
      
        
      A room anyone signed in can join without a call ID. The server has to issue its tokens, so this needs one small backend endpoint.

      Reference
      Calls kit
      
        
      
          
      
            
      MemberWhat it does
      
            
              
      WibeChatCalls(context, appServerUrl)Creates the kit. Make one per app.
      
              
      session: StateFlow<Session?>The signed-in user, or null.
      
              
      phase: StateFlow<CallPhase>Idle, Connecting or InCall.
      
              
      room: RoomThe SDK room, for video renderers and the local participant.
      
              
      signIn(email, password)Signs in and remembers the session.
      
              
      register(email, password, fullName)Creates an account and signs in. Password: 8+ characters.
      
              
      signOut()Hangs up and forgets the session.
      
              
      startCall(email, type)Rings someone and connects. Returns the call ID.
      
              
      join(callIdOrText)Answers and connects. Accepts a bare ID or a whole invite message.
      
              
      hangUp()Leaves; cancels a call nobody answered, otherwise ends it.
      
              
      release()Hangs up and frees the room for good.
      
              
      CallIds.inviteMessage(callId)Text to share so the other person can paste and join.
